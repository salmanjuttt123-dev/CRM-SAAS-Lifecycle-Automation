# Zapier Integration

## Purpose

Zapier connects different SaaS tools together without requiring custom code.

## Example Zaps

```text
Facebook Lead Ads → HubSpot
Calendly Booking → Google Calendar
HubSpot Deal Won → Slack Notification
Stripe Payment → CRM Customer Update
Google Sheets Row → GoHighLevel Contact
```

## Common Actions

- Create contact
- Update contact
- Create deal
- Send email
- Send Slack message
- Add row to Google Sheets
- Trigger follow-up workflow
