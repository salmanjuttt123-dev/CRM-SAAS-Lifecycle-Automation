# GoHighLevel Integration

## Purpose

GoHighLevel is used for CRM automation, pipeline management, SMS/email follow-ups, appointment booking, and client communication.

## Connected Workflows

- Contact creation
- Pipeline updates
- SMS follow-ups
- Email campaigns
- Appointment reminders
- Missed call text back
- Review requests
- Reactivation campaigns

## Example Automation

```text
New lead enters GoHighLevel
→ Contact is created
→ Pipeline opportunity is added
→ SMS confirmation is sent
→ Email follow-up sequence starts
→ Sales task is created
```
