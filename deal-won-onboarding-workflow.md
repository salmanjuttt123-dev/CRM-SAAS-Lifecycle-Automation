# Deal Won to Onboarding Workflow

## Purpose

This workflow starts the customer onboarding process after a deal is marked as won.

## Automation Flow

```text
Deal marked as Won
→ Lifecycle stage updates to Customer
→ Welcome email is sent
→ Invoice or payment request is created
→ Onboarding checklist is created
→ Client folder is created
→ Customer success team is notified
```

## Onboarding Actions

- Create account
- Send login details
- Assign customer success owner
- Create onboarding checklist
- Book training call
- Send welcome sequence
- Track onboarding progress
