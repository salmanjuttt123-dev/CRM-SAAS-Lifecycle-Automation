# Win-Back Workflow

## Purpose

This workflow re-engages lost leads, inactive customers, and churned users.

## Automation Flow

```text
Lead or customer becomes inactive
→ CRM status changes to Inactive
→ Re-engagement sequence starts
→ Special offer or update is sent
→ Sales or customer success team is notified
```

## Win-Back Triggers

- No response after 14 days
- No login activity for 7 days
- Cancelled subscription
- Lost deal
- Missed appointment

## SaaS Tools Used

- HubSpot
- GoHighLevel
- Zapier
- n8n
- Email/SMS tools
