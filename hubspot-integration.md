# HubSpot Integration

## Purpose

HubSpot is used as the main CRM for managing contacts, deals, lifecycle stages, sales pipelines, customer communication, and reporting.

## Connected Workflows

- Lead capture
- Lead qualification
- Deal creation
- Pipeline stage updates
- Email follow-ups
- Customer onboarding
- Renewal reminders
- Customer success tracking

## Example Automation

```text
New contact created in HubSpot
→ Lead source is checked
→ Contact is scored
→ Deal is created
→ Sales owner is assigned
→ Follow-up workflow starts
```
