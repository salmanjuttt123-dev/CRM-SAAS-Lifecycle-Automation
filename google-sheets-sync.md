# Google Sheets Sync

## Purpose

Google Sheets can be used for reporting, backup data, manual review, or lightweight CRM records.

## Example Syncs

```text
New lead → Add row to Google Sheets
Qualified lead → Update row status
Deal won → Add customer record
Renewal due → Add to renewal tracker
```

## Tools Used

- Zapier
- n8n
- HubSpot
- GoHighLevel
- Google Sheets
