# Appointment Booking Workflow

## Purpose

This workflow moves a qualified lead from interest to a booked call, demo, consultation, or appointment.

## Automation Flow

```text
Lead clicks booking link
→ Calendly appointment is created
→ CRM deal stage updates to Booked Call
→ Google Calendar event is created
→ Confirmation email is sent
→ SMS reminder is scheduled
→ Sales rep is notified
```

## CRM Pipeline Stages

```text
Booked Call
Demo Scheduled
Consultation Scheduled
No Show
Rescheduled
```

## SaaS Tools Used

- Calendly
- Google Calendar
- HubSpot
- GoHighLevel
- Zapier
- n8n
- Twilio
